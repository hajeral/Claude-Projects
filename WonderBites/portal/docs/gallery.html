How to reproduce

The gallery is regenerated by the QA run (last step of qa/run_all.sh) or on its own:

bash qa/run_all.sh                 # full QA run: render matrix, click-through, flows, inventory, gallery
python3 qa/gallery.py              # gallery only (≈ 2–3 min)
python3 qa/gallery.py m-orders     # re-shoot single routes

Requirements: Python 3 with playwright (Chromium) and Pillow. The app is opened from index.html via file://; both portals are signed in with the demo accounts, date range = last 30 days ending on the demo today. Detail routes show the first record of their list.
